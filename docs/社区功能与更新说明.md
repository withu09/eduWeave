# 社区功能与服务器更新

本次把原来仅存在浏览器内的社区演示，接入项目现有数据库。新版本支持：

- 多人共享动态，支持 Markdown、LaTeX、表格和最多 4 张图片。
- 评论与回复；删除父评论时保留后续回复。
- 点赞、取消点赞、收藏与取消收藏，同一身份重复请求不会重复计数。
- 按内容、话题或昵称搜索，精确话题筛选，最新 / 热门排序与分页加载。
- 我的发布、我的收藏、修改昵称、编辑自己的动态、删除自己的动态和评论。
- 独立帖子分享链接，图片放大查看，本地草稿保留、失败重试、手机布局。

## 身份与存储

当前采用浏览器独立的访客身份，首次进入自动建立，可修改昵称。服务器只保存身份凭证的哈希值，编辑和删除操作会验证内容归属；相同昵称不会获得他人的编辑权限。身份凭证通过 `X-Community-Token` 传递，可与现有网关的评审账号密码并用。

身份保存在当前浏览器中。不同设备或清除浏览器数据后会成为新身份，原动态继续保留，但新身份不能管理原身份的内容。这次实现的范围是基础社区；跨设备账号登录和社区管理后台未包含在本次更新中。

动态、评论、互动及图片保存在现有 PostgreSQL 数据库中，重建应用容器后继续保留。启动时自动创建 5 张 `community_*` 数据表。页面从空的真实社区开始；原浏览器中的演示帖子不会自动发布到服务器，旧的本地存储也不会被本次更新删除。

图片支持 JPG、PNG、WebP，每张原图最多 5 MB、1600 万像素，服务端验证后缩放到最长边 1920 像素并重新编码为 WebP。尚未发布的图片保留 24 小时，后续上传时清理过期图片；长时间未发布的图片草稿需要重新上传。

## 已部署服务器：使用更新包

更新包名称为 `community-update-20261108.tar.gz`，含新页面成品、相关源文件、测试和安装脚本。它使用服务器现有的项目配置和数据库。

1. 将更新包上传到服务器任意临时目录，例如 `/tmp`。
2. 解压并运行脚本，将 `/opt/eduweave` 换成服务器上实际的项目目录：

   ```bash
   cd /tmp
   tar -xzf community-update-20261108.tar.gz
   bash community-update-20261108/install_community_update.sh /opt/eduweave
   ```

3. 脚本自动选择项目中的 `.env.bailian`，没有时选择 `.env`。使用其他配置文件时，通过第二个参数指定：

   ```bash
   bash community-update-20261108/install_community_update.sh /opt/eduweave .env.production
   ```

4. 脚本先备份数据库和本次涉及的旧文件，再重建后端与网关，最后检查社区接口。备份放在原项目的 `backups/community-日期时间-进程号/` 中。
5. 打开原网站并刷新，使用普通窗口和无痕窗口分别进入社区，验证两者可以看到彼此发布的动态、评论和真实点赞数。

此脚本适用于仓库提供的 Docker Compose 生产部署，要求现有 PostgreSQL 服务已运行。如果服务器使用宝塔、其他进程管理方式或不同服务名，需要按实际部署方式安装 `backend/requirements.txt`、更新后端文件和前端 `dist`，并重启应用。

## 源码方式更新

项目源码已同步修改。若直接同步源码到服务器，先在前端目录生成同域访问的页面：

```bash
cd frontend
npm ci
VITE_API_URL="" npm run build
cd ..
docker compose -f docker-compose.yml -f docker-compose.prod.yml --env-file .env.bailian up -d --no-deps --build eduweave-api eduweave-gateway
```

生产网关使用预先生成的 `frontend/dist`，因此只上传前端源文件并重启网关不足以更新页面。新后端依赖 Pillow，需要重建后端镜像。

## 验证与回退

接口测试使用独立临时 SQLite 数据库，覆盖数据持久化、身份验证、编辑权限、点赞去重、评论回复、搜索排序、分页、图片校验和级联删除：

```bash
cd backend
python -m unittest discover -s tests -p test_community.py -v
```

页面测试会自行启动本地测试服务，使用一次性数据库和两个独立浏览器身份，不访问线上站点或模型服务。先构建同域前端，再运行：

```bash
cd frontend
npm ci
npx playwright install chromium
VITE_API_URL="" npm run build
npm run test:community
```

测试所用 Python 需要已有 FastAPI、SQLAlchemy、Pillow、python-multipart、psycopg2-binary、Uvicorn；接口测试另需 httpx。可用 `EDUWEAVE_TEST_PYTHON` 指定 Python 路径，也可用 `EDUWEAVE_TEST_BROWSER=chrome` 或 `msedge` 使用已安装浏览器。测试截图位于 `.local-build/community-browser/`。原有前端对话测试仍可运行 `node tests/conversation.mjs`。

如需回退程序，先将安装脚本输出的备份目录中的 `files` 内容复制回项目，再按原配置重建这两个服务：

```bash
cp -a /opt/eduweave/backups/community-实际备份目录/files/. /opt/eduweave/
cd /opt/eduweave
docker compose -f docker-compose.yml -f docker-compose.prod.yml --env-file .env.bailian up -d --no-deps --build eduweave-api eduweave-gateway
```

回退程序可以保留新增社区表及其中的数据。数据库备份文件另存为 `database.dump`，供确有必要时恢复；日常回退页面与接口不需要覆盖数据库。

## 新增接口

基础路径为 `/api/community`，写入请求携带 `X-Community-Token`。读接口可匿名查看；携带身份时返回个人点赞、收藏和归属状态。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST | `/session` | 创建访客身份；携带凭证时恢复当前身份 |
| PATCH | `/me` | 修改昵称 |
| GET / POST | `/posts` | 搜索分页 / 发布动态 |
| GET / PATCH / DELETE | `/posts/{id}` | 查看 / 编辑 / 删除动态 |
| PUT | `/posts/{id}/like`、`/bookmark` | 设置互动状态，参数为 `{"active": true/false}` |
| GET / POST | `/posts/{id}/comments` | 分页查看 / 发布评论或回复 |
| DELETE | `/comments/{id}` | 删除自己的评论 |
| GET | `/tags` | 最近 1000 条动态中使用最多的 12 个话题 |
| POST | `/images` | 上传并处理图片 |
| GET | `/images/{id}` | 读取图片 |
